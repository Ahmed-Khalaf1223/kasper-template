# 🎨 Kasper Template Two

A modern and fully responsive landing page built from scratch using **HTML5** and **CSS3**.

This project is a front-end implementation of the Kasper template, focusing on clean structure, responsive design, CSS layouts, and modern UI techniques.

## 🎯 Sections

### 🏠 Landing

Hero section with background image, overlay, navigation arrows, and slider bullets.

### 💼 Services

Displays the available services using Font Awesome icons and responsive layouts.

### 🎨 Design

A feature section highlighting responsive design, clean code, modern design, and browser compatibility.

### 🖼️ Portfolio

Responsive portfolio gallery with categories and image hover animations.

### 🎥 Video

Full-width background video section with an overlay and call-to-action button.

### 👨‍💻 About

Introduction section with a responsive image.

### 📊 Statistics

Displays project statistics such as:

* Coffee Drinks
* Completed Projects
* Mail Sent
* Awards Received

### ⭐ Testimonials & Skills

Testimonials with user images alongside animated-style skill progress bars.

### 💰 Pricing

Four pricing plans:

* Basic
* Premium
* Pro
* Platinum

### 📩 Subscribe

Email subscription section with a responsive form.

### 📞 Contact

Contact form with name, email, message, phone numbers, and address information.

### 🦶 Footer

Social media icons, branding, and copyright information.

## 📱 Responsive Design

The website is fully responsive and adapts to different screen sizes:

* 📱 Mobile
* 📲 Tablet
* 💻 Desktop
* 🖥️ Large Screens

CSS Media Queries are used to create a responsive layout across different devices.

## ⚙️ How to Run

No installation or build process is required.

Simply clone the repository:

```bash
git clone https://github.com/Ahmed-Khalaf1223/kasper-template.git
```

Navigate to the project:

```bash
cd kasper-template
```

Then open:

```text
index.html
```

in your browser.
